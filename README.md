# 📊 Projet_Ventes - Analyse des Ventes

Projet Python pour analyser les ventes d'une entreprise.

## 📁 Fichiers
- `analyse.py` : Le code Python qui fait l'analyse
- `ventes.csv` : Les données des ventes
- `graphique_*.png` : Les graphiques générés

## 📈 Ce que fait le projet
- Calcule le revenu total
- Trouve le produit le plus vendu
- Affiche le revenu par mois
- Génère des graphiques

## ▶️ Comment l'exécuter
```bash
python analyse.py
